# 🚗 Garagem de Carro — Sistema de Estacionamento

## 📋 Sobre o Projeto

O **Garagem de Carro** é um projeto de prototipagem de alta fidelidade de um sistema de gerenciamento de estacionamento, desenvolvido como atividade acadêmica.

O projeto apresenta uma proposta de interface para facilitar o controle de veículos, clientes, vagas e funcionários, além do acompanhamento das entradas e saídas do estacionamento.

## 🎯 Objetivos

* Desenvolver um protótipo visual de um sistema de estacionamento.
* Organizar as principais funcionalidades em uma interface intuitiva.
* Facilitar a visualização e o controle das vagas.
* Representar os processos de entrada e saída de veículos.
* Planejar a experiência dos usuários antes da implementação do sistema.

## ⚙️ Funcionalidades Representadas

* 🔐 **Login:** tela de acesso ao sistema.
* 🏠 **Menu principal:** painel inicial com resumo das informações do estacionamento.
* 🚘 **Registrar entrada:** interface para registrar a entrada de veículos.
* 🚗 **Registrar saída:** interface para consultar registros e confirmar a saída de veículos.
* 👥 **Cadastro de clientes:** formulário para organizar os dados dos clientes.
* 📊 **Relatórios:** visualização de informações e registros do estacionamento.
* 🧑‍💼 **Cadastro de atendentes:** interface para registrar funcionários e seus dados de acesso.
* 🅿️ **Visualização de vagas:** representação visual da ocupação e disponibilidade das vagas.

## 🎨 Tipo de Projeto

**Protótipo de alta fidelidade:** modelo visual detalhado que representa a aparência e a organização das telas de um sistema, permitindo compreender como ele poderá funcionar antes de seu desenvolvimento.

## 🛠️ Ferramentas Utilizadas

* **Canva:** utilizado na elaboração dos materiais visuais do projeto.
* **Google Docs:** utilizado para a documentação e organização das informações.

## 📚 Finalidade Educacional

O projeto foi desenvolvido para fins educacionais, com foco no planejamento de sistemas, na prototipagem de interfaces e na organização das funcionalidades de uma aplicação.
